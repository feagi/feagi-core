-----------------------------------------------------------

JS:     /swagger-ui/swagger-ui-bundle.js
Spec:   /api-docs/openapi.json

Filesystem (this folder) -> URL, if swagger_site/ is served at /swagger-ui/:
  feagi-server.html     -> /swagger-ui/feagi-server.html
  swagger-ui.css        -> /swagger-ui/swagger-ui.css
  swagger-ui-bundle.js  -> /swagger-ui/swagger-ui-bundle.js
